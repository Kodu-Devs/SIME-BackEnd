🧯 SIME (Sistema de Inventario y Mapeo de Extintores) Plataforma diseñada para administrar la ubicación, disponibilidad y estado físico de los extintores dentro de una organización. SIME centraliza la información de seguridad para facilitar la toma de decisiones mediante:

Mapeo y Geolocalización: Ubicación exacta de los extintores por edificio o área.

Control de Mantenimiento: Calendario automatizado para recargas, revisiones y reemplazos.

Gestión de Inventario: Historial de uso, reportes de siniestros y control de disponibilidad en tiempo real.

Capacitación: Módulos integrados para la administración y formación de brigadas de seguridad.
